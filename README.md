# Social Media Scraper (Chrome Extension)

A simple Chrome Extension to scrape recent posts from **Twitter (X)** and **Reddit** and download them as a CSV file.

## 🚀 Features
- Works on **Twitter/X** and **Reddit** profiles.
- Scrapes the last **20 posts** automatically.
- Extracts **Post Text**, **Timestamp**, and **Author**.
- Automatically downloads data to a **CSV file** (Excel compatible).
- No API keys required (uses your active browser session).

## 🛠️ Installation

1. Clone or download this repository.
2. Open Google Chrome and go to `chrome://extensions/`.
3. Enable **Developer Mode** (toggle in the top right).
4. Click **Load Unpacked**.
5. Select the `social-scraper` folder.

## 📖 How to Use

1. Pin the extension icon to your Chrome toolbar.
2. Log in to your Twitter or Reddit account.
3. Click the extension icon.
4. Paste the target profile URL:
   - Example: `https://x.com/elonmusk`
   - Example: `https://www.reddit.com/r/technology/`
5. Click **Scrape Recent Posts**.
6. Wait 5 seconds. The `.csv` file will download automatically.
